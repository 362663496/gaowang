# 用户与商品清理及查询识别修复

## Goal

安全移除不再需要的用户与商品字段，并让飞书自然语言查询的失败可诊断、可恢复且忠实表达用户问题。

## Background

- 用户当前只有创建和列表接口；历史库存流水通过外键引用操作人，物理删除会破坏审计链。
- 商品 `DefaultSaleCents` 目前不仅显示在商品页，还作为销售出库收入和毛利的运行时价格源；移除后的收入语义需要产品决策。
- 飞书所有非空文本都会调用 DeepSeek，不存在“店铺排行”本地兜底。2026-08-01 20:07:00 的查询失败后，同一句在 20:07:26 和 20:07:51 成功，符合瞬时模型调用/响应失败；当前实现把超时、HTTP 状态、响应 JSON 和计划校验错误全部折叠为同一个提示，且失败路径没有安全诊断日志。
- 当前飞书统计计划只允许一个 `group_by`；“按商品排序并列出店铺各占多少”被简化为店铺排行，无法表达商品 × 店铺二维结果。

## Task Map

1. `08-01-soft-delete-users`：用户软删除、会话失效和历史引用保护。
2. `08-01-remove-product-sale-price`：移除商品默认销售价并按确认后的业务语义收敛收入/毛利链路。
3. `08-01-optional-inventory-notes`：为入库和销售出库增加可选备注并复用流水展示。
4. `08-01-fix-lark-query-recognition`：增加模型失败诊断与瞬时恢复，并处理二维统计表达能力。

## Delivery Dependencies

- 用户软删除可独立实施；最终集成需确认飞书操作人统计仍能展示已删除用户的历史姓名。
- 移除商品销售价必须先于飞书查询扩展完成，后者只能使用收敛后的数量、采购成本和库存价值指标。
- 出入库备注在销售价清理后实施，再由飞书查询子任务完成备注展示集成验证。
- 父任务只负责跨子任务验收、提交和部署，不承载重复实现。

## Requirements

- R1：用户删除必须保留历史流水、审计日志等引用，并立即阻止被删账号继续登录或使用已有会话。
- R2：商品创建、编辑、列表和接口不再暴露无意义的默认销售价。
- R3：移除销售价后停止收入和毛利统计，不新增销售出库实际售价录入；报表和飞书查询只保留销售数量、采购成本、库存价值等有来源的数据。
- R4：飞书查询不得使用固定命令抢占自然语言；模型成功计划仍须经过白名单校验并使用参数化本地查询。
- R5：模型瞬时失败应有有限恢复能力，并记录不含密钥、原始提示词或供应商响应正文的安全诊断信息。
- R6：用户明确要求多个统计维度时，不得静默降级为单维结果。
- R7：飞书自然语言查询优先扩展现有库存业务域，而不是开放任意数据库访问；候选范围包括商品、当前库存、店铺、出入库流水和操作人，以及总计、明细、排行、趋势、占比和同期对比。
- R8：AI 可根据问题选择受控的卡片表达方式，服务端必须依据真实查询结果渲染合法飞书卡片；不得直接发送模型生成的任意卡片 JSON 或数值。
- R9：流水记录列表删除收入和毛利列，日期列紧跟在采购/成本金额列之后。
- R10：入库和销售出库支持最多 500 字符的可选备注，并随流水和飞书消息展示。

## Acceptance Criteria

- [ ] 四个子任务都有独立、可验证的验收标准和回滚边界。
- [ ] 用户软删除不会破坏历史引用，被删用户立即失去访问能力。
- [ ] 商品默认销售价从确认范围内完整移除，相关指标语义一致。
- [ ] 飞书“暂时不可用”可区分并诊断失败阶段；瞬时失败按确认策略处理。
- [ ] “按商品排序并列出店铺各占多少”等二维问题得到明确支持或明确告知不支持，不再静默变成店铺排行。
- [ ] 汇总、排行、明细、二维结果、趋势和对比使用与语义匹配的卡片结构，所有展示数值都来自服务端查询结果。
- [ ] 流水表按“数量 → 采购/成本金额 → 日期”的顺序展示，不再出现收入或毛利。
- [ ] 入库、销售出库可留空或填写备注；合法备注持久化并展示，超限不产生库存变更。

## Confirmed Decisions

- 移除默认销售价后，不新增实际销售价录入，并停止收入/毛利统计。
- 飞书查询扩展到库存业务域内全部只读数据，最多二维组合，覆盖常用及明确日期范围；统计覆盖全部匹配数据，卡片最多展示 10 行。
- 飞书卡片采用受控 AI 方案：模型选择白名单展示意图与重点，服务端按真实查询结果渲染。
- 用户软删除后立即禁用并撤销会话，默认列表隐藏；用户名和邮箱继续保留且不可复用，本次不提供恢复入口。
- DeepSeek 仅对网络异常、超时、429 和 5xx 重试一次，整次识别最多等待 10 秒；JSON、计划校验和不支持问题不重试。
