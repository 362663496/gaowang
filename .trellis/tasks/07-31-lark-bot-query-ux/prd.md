# 飞书机器人查询体验升级

## Goal

减少重复命令，让固定库存群成员既能使用简短固定命令，也能用日常中文查询库存；所有包含具体商品的回复都尽量展示与商品一一对应的图片。

## Background

- 当前 `查商品` 会包含尚无库存快照的商品，`查库存` 只包含已有库存快照的商品；除此之外，两者搜索、排序与展示字段相同，保留两个入口的价值很低。
- 当前仅唯一商品结果会尝试附带图片，多商品结果为纯文本。
- 现有商品、库存快照和流水数据已经足够支持概览、低库存、最近流水与当日变动，无需新增数据表。
- 机器人继续只服务一个配置群，并保持只读。

## Requirements

### R1. 收敛固定命令

- 唯一商品/库存入口为 `查库存 <名称或编码>`，模糊匹配全部未归档商品；没有库存快照的商品按数量 0 展示。
- 旧 `查商品` 不再执行重复查询，只返回迁移提示与新的用法。
- 保留 `低库存` 和 `帮助`。
- 新增以下只读命令：
  - `库存概览`：未归档商品数、总库存数量、按当前商品采购价计算的库存金额、低库存数和无库存数。
  - `查流水 [名称或编码]`：有参数时按商品名称或编码模糊筛选，无参数时返回全局最近流水。
  - `今日变动`：按上海自然日汇总入库、销售出库和库存调整的笔数及数量变化。
- 帮助卡片只展示当前有效命令，并给出大白话示例。

### R2. 商品图片

- 任何回复只要包含一条或多条具体商品信息，每条商品信息都应显示自己的商品图片。
- `查库存`、`低库存` 和 `查流水` 最多返回 5 条；多结果放在一张卡片中，图片与对应文字相邻。
- 图片使用紧凑缩略图布局，不再横向铺满整张卡片；图片不能压过商品名称、数量和库存状态等核心信息。
- 商品无图片、图片文件缺失或上传飞书失败时，只降级该商品的图片，文字结果仍正常返回。

### R3. 卡片信息层级

- 库存操作通知和查询卡片都要区分主次：商品名称、编码、数量变化、库存结果和状态为主要信息，操作人、时间、店铺和原因作为次级信息。
- 关键数字使用粗体，并配合语义色标题和状态符号：入库/增加为绿色，出库/减少为红色，低库存为橙色，普通说明保持中性。
- 字段采用分组或双列布局，避免连续文本堆叠；编码继续使用等宽样式，时间保持易读的上海时区格式。

### R4. DeepSeek 自然语言解析

- 固定命令优先由本地解析器处理；只有不匹配固定命令的文本才请求 DeepSeek。
- 使用 DeepSeek 官方 Chat Completions API、`deepseek-v4-flash` 非思考模式和 JSON Output；模型名可通过服务器环境变量覆盖。
- DeepSeek 只把文本转换成以下白名单意图及参数：查库存、低库存、库存概览、查流水、今日变动、帮助、无法识别。
- 至少覆盖 20 条代表性日常中文测试语料，包含商品数量/价格/状态、低库存、库存概览、最近流水和今日变动的不同表达方式。
- AI 只接收去除机器人提及后的用户文本，不接收库存数据、凭证、聊天历史或数据库结构；不保存多轮对话状态。
- 系统严格校验 AI 返回的意图、JSON 结构和关键词长度；AI 不能生成 SQL、调用写操作或决定金额与库存结果。
- DeepSeek API Key 仅通过服务器环境变量配置，不进入仓库、日志、审计或飞书回复。未配置 Key 时固定命令仍可用。
- DeepSeek 超时、限流、异常、空响应或非法输出时返回简短降级提示和固定命令帮助，不影响长连接与后续消息。

### R5. 查询与访问边界

- 商品结果继续按名称、编码、ID 稳定排序，最多 5 条，超出时提示缩小关键词。
- 低库存沿用 `阈值 > 0` 且 `数量 <= 阈值`，无库存快照视为数量 0。
- 流水按创建时间、ID 倒序，显示商品、类型、数量变化、操作人、店铺（如有）和时间。
- 所有金额始终使用当前商品价格计算。
- 仅处理配置群内真实 @机器人的消息；其他群、私聊、@所有人和重复消息继续被拒绝。
- 每次成功解析均写入不含凭证和原始模型响应的审计记录。

## Acceptance Criteria

- [ ] AC1：帮助中只有一个商品/库存入口；`查商品` 返回迁移提示，`查库存` 可查到无快照商品并显示数量 0。
- [ ] AC2：单商品、多商品、低库存和流水结果中的每条具体商品均带对应紧凑缩略图；单张图片失败只影响该图。
- [ ] AC3：操作通知与查询卡片的主次字段清晰，关键数量和状态有粗体、语义色标题及状态符号，图片不会横向占满卡片。
- [ ] AC4：`库存概览`、`查流水 [关键词]`、无参数 `查流水` 和 `今日变动` 的范围、排序、上限、空结果均有自动化测试。
- [ ] AC5：固定命令不调用 DeepSeek；至少 20 条代表性日常中文可映射到全部白名单意图，并限制关键词长度。
- [ ] AC6：未知意图、非法 JSON、非法意图、空响应、非 2xx、超时和未配置 Key 均安全降级，固定命令仍正常工作。
- [ ] AC7：DeepSeek 请求不包含库存数据、凭证或历史消息；日志、审计和错误信息不包含 API Key 或原始模型响应。
- [ ] AC8：固定群、提及、去重、只读查询、有界队列和飞书发送失败隔离规则保持不变。
- [ ] AC9：Go 格式化、完整测试和静态检查通过；部署后固定命令、自然语言、图片、卡片样式与降级路径在新库存群完成回归验证。

## Out of Scope

- 库存以外的通用 AI 问答。
- 飞书内执行入库、出库、调整或其他写操作。
- 多群、私聊、用户身份映射或多轮上下文记忆。
- 定时日报、交互按钮、卡片回调或新增数据库表。
